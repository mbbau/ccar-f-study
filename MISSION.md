# Mission: Certificación CCAR-F (Claude Certified Architect – Foundations)

## Why
Quiero certificarme como Claude Certified Architect para validar mis habilidades en el ecosistema Anthropic y poder aportar valor real con Claude en mis proyectos de datos e IA y los de mi empresa. El punto de corte es 720/1000; mi meta es ≥ 800.

## Success looks like
- Aprobar el examen CCAR-F el 27/10/2026 con puntaje ≥ 800/1000
- Poder diseñar un sistema agéntico multi-step con Claude, eligiendo correctamente entre orchestrator, routing y parallelization patterns
- Configurar Claude Code con CLAUDE.md, specs y skills para un proyecto real de analytics engineering
- Construir un servidor MCP funcional en Python que exponga herramientas a Claude
- Escribir system prompts con structured outputs (JSON schema) y saber cuándo usar tool_use vs. direct generation
- Decidir cuándo escalar a un humano (human-in-the-loop) vs. confiar en el agente, aplicando guardrails

## Constraints
- **Tiempo:** 4 semanas (28/9 – 23/10/2026), ~90 min/día hábil (20 días), examen el 27/10
- **Formato:** 50% teoría exam-focused + 50% labs prácticos en mi stack (Python, SQL, BigQuery, dbt)
- **Nivel actual:** BI Developer / Analytics Engineer con nivel medio en agentes (chatbot con OpenAI Agents SDK), nivel bajo en servidores MCP
- **Idioma:** explicaciones en español, términos técnicos en inglés (como aparecen en el examen)
- **Herramientas:** ya uso Claude Code con specs y skills propias

## Out of scope
- Certificaciones de otros providers (AWS, GCP AI certs)
- Fine-tuning de modelos Claude
- Desarrollo de frontends web complejos
- Aprender otros SDKs de agentes (LangChain, CrewAI, etc.) — el foco es 100% ecosistema Anthropic
- Contenido fuera del blueprint CCAR-F (ej: Claude para imágenes/audio si no está en el examen)
