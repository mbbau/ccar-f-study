Salida estructurada (4.3)

  • Tool cuyo input_schema es el formato → leer tool_use.input.
  • any: varios schemas, documento desconocido · tool: esa extracción sí o sí · auto: puede responder texto.
  • API actual (Opus/Sonnet 5.5): any/tool → 400; usar auto + strict: true o output_config.format.
  • Nullable (["string","null"]) si el dato puede faltar → evita inventos.
  • Enum + "other" + campo detalle; "unclear" para ambiguos.

Message Batches (4.5)

  • −50% · hasta 24 h · sin SLA · custom_id (orden no garantizado).
  • Sí: nocturno, semanal, histórico. No: bloqueante (pre-merge), humano esperando.
  • Sin loop con client tools dentro de un request.
  • Fallas: reenviar solo los fallidos por custom_id, con la corrección.
  • SLA: frecuencia de envío = SLA − 24 h (o menos).
  • Refinar el prompt con una muestra antes del volumen.
