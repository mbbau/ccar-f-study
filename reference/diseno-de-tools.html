Checklist de una description

  • Qué hace · cuándo usarla · cuándo no · qué devuelve · límites.
  • 3–4 oraciones como mínimo. Cada parámetro con su propia description y un ejemplo.
  • Sin superposición con otras tools; prefijo por servicio (dwh_).
