Messages API

Ficha rápida. Lección: 0001.

Request

CampoQué es
modelModelo a usar.
max_tokensTope de tokens de la respuesta. Si se alcanza → stop_reason: max_tokens.
systemInstrucciones generales. Parámetro de primer nivel, no un mensaje.
messagesHistorial completo; roles user / assistant alternados.
toolsDefiniciones de tools (name, description, input_schema).

Response

CampoQué es
id, type, rolemsg_…, "message", "assistant".
contentLista de bloques tipados (text, tool_use, …). No hay choices.
modelModelo que respondió.
stop_reasonPor qué se detuvo. Gobierna el loop (ver agentic loop).
stop_sequenceQué stop sequence se disparó, si aplica.
usageinput_tokens, output_tokens.

Reglas

  • Stateless: cada request lleva toda la conversación. input_tokens crece turno a turno.
  • Texto: "".join(b.text for b in r.content if b.type == "text").
  • tool_result viaja con role user (no existe role tool).
